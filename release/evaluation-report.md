> **读法（这一段决定了主结论怎么解读）**：连**只在到期当天才打折**这种最精准的清货方式，最好的档位（仅到期日9折）也只有 -1.2% 的经营毛利，损耗率从 12.45% 降到 10.99%。也就是说：**在这个仿真器里，价格不是解决损耗的正确杠杆**——打折能在'最后一刻'把注定报废的货换成钱，但同一折扣会同时施加在**所有**本来就能按原价卖掉的货上，后者损失大于前者收益。

这不是评测写错了，而是仿真参数的**结构性后果**，原因有两条，都可以核对：

1. **弹性绝对值跨在 1 的两侧**：仿真器真值 |ε| ∈ [0.63, 1.27]（中位 0.90）。常弹性需求下收入 `R ∝ p^(1−ε)`，当 `|ε| < 1` 时**收入随价格上升**，降价直接减少收入；约六成单品落在 `|ε| < 1` 区间。
2. **补货量外生且与定价无关**：三种策略拿到完全相同的到货计划（见第 1 节进货量差异≈0）。
   当库存本就过剩时，定价只能在「多卖一件」和「每件都少赚」之间交换，而**减少进货才是根治损耗的办法**——那是补货模块的问题，不是定价模块能解决的。

因此下文对 MODEL 的评价标准是：**它能不能比经验规则更划算地完成同样的损耗率下降**，而不是「能不能既降损耗又涨毛利」。

## 4. 结论（含波动范围）

### MODEL vs FIXED（固定价格（基线1，成本加成不打折））

**在「需求 = 基准需求 × exp(−弹性 ×(折扣−1)) × 时段因子 × 周内因子 × 泊松扰动，且关闭推送」的仿真假设下，MODEL 相对 FIXED 把损耗率从 13.58% 降到 7.84%（绝对 -5.74 个百分点，相对 -42.3%），经营毛利从 68,370 元变为 60,194 元（-11.96%）。**

- 损耗率差（MODEL−FIXED）：均值 -5.743 pp，标准差 1.064 pp，范围 [-7.974, -4.092] pp，2.5%~97.5% 分位 [-7.547, -4.168] pp，配对 t 检验 p = 1.02e-15（20 个种子）
- 经营毛利差：均值 -8,175.6 元，标准差 1,588.7 元，范围 [-11,984.9, -5,815.3] 元，p = 2.447e-15
- 毛毛利差（不扣报废）：均值 -14,631.0 元 → 说明收益差是否来自「少报废」这件事本身
- 缺货率差：均值 -0.035 pp；售出率差：均值 +7.148 pp
- **逐种子胜负：0/20 个种子上 MODEL 的经营毛利更高**

## 6. 假设边界（结论只在下列条件下成立）

1. **数据来自自研仿真器**，不是真实门店流水；需求函数、参数分布、补货节奏都是我们设定的。
2. 需求形式为 `λ = base_i · exp(−ε_i·(p/base_i − 1)) · hour_factor · weekday_factor`，
   弹性不随价格区间变化（常弹性），且单品之间**没有交叉价格效应**（黄瓜打折不会抢苹果的客人）。
3. 补货策略对三种策略**完全相同**（上表进货量/批次数差异≈0 已验证），所以本评测隔离的是「定价」这一个变量。
4. 本评测**关闭了推送**（`promo_lift ≡ 1`）：推送带来的增量需求不进入对比，推送效果单独在推送模块评估。
5. 消费者是同质的、无策略性等待行为（不会「知道明天更便宜所以今天不买」），也没有囤货。
6. 每个种子只有 30 天测试期，季节性与节假日效应未建模；跨种子波动已用均值±标准差与逐种子差值如实给出。

## 7. 局限（至少 3 条，答辩会就这几条提问）

1. **仿真自证风险（最重要）**：结论只在「我们自己的仿真器假设」下成立。仿真器的需求函数就是
   「对价格敏感、对剩余天数不敏感」的形态，模型定价天然占优；换一台仿真器结论可能变化。
   我们能做到的缓解是：① 需求参数用公开真实蔬菜数据校准（`docs/02`）；② 明确列出假设边界；
   ③ 主动报告模型**没赢**的指标与种子。**但不能声称这是真实门店的因果结论。**
2. **本仿真器里价格不是解决损耗的正确杠杆**：第 2 节的扫描显示，连「只在到期当天打 9 折」都亏 1.2%。
   因为约六成单品 |ε| < 1（常弹性下收入随价格上升），且补货量外生、库存本就过剩。
   要根治损耗应当调整**补货量**，而补货在本评测里对三个策略完全相同——这是评测的边界，不是模型的能力边界。
3. **弹性估计的内生性与截断偏差**：历史价格由规则策略决定（库存压手才打折），且缺货日销量被截断，
   两个偏差**同向**——都会让 |弹性| 被低估，从而让 MODEL 打折偏保守。因此本报告里 MODEL 的优势是
   偏保守的下界；反过来，如果 MODEL 输了，也不能说明模型思路错，只能说明它在低估弹性的情况下不够激进。
4. **批次粒度简化**：真实店主不会逐箱登记，本评测按「品类+到货日」合成批次；批次级 DP 还假设
   单批次在单品内的需求份额不变，未建模同单品多批次之间的互相蚕食（该近似对「留到明天」的价值略偏保守）。
5. **推送环节未纳入本评测**：`docs/00` 里的「客流适配推送」是独立链路，本报告的 30 天测试期没有开推送，
   所以这里的收益**不含**推送带来的增量客流。
6. **单店、单场景、30 天**：未覆盖节假日、天气、竞品降价、供应链断货等外生冲击；
   也未建模顾客对频繁变价的信任损耗（真实店里天天打折会伤价格锚点）。
7. **成本与损耗参数是区间估计**：公开数据是蔬菜（散称、当天出清），迁移到水果（标品、可隔夜）
   时只保留了「损耗率」概念与量级，数值不完全可比。
