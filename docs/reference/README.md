## 与原 Excel 的关系

参考架构共 7 个工作表：系统架构 / 数据库表 / 临期判定 / 定价引擎 / 推送 / 仿真与评测 / 开发顺序。
其中我们**全部采纳**的是：批次管库存（FIFO 扣减）、临期判定公式链（新鲜度 / 预计可售天数 / 有风险）、
三策略对照评测（固定价 / 规则版 / 模型版）、店主确认留痕、按高峰与偏好选人推送；
**有差异或降级实现**的是：定价引擎（做成离线产物而非独立服务）、本地大模型（模板 + 可替换接口）、
MySQL（提供 DDL 但演示用 H2）、每小时扫描（做成只读派生计算，不自动改价）。
逐条对照与理由见 `docs/07`。
